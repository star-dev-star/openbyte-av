What is OpenByte AV?

OpenByte AV is a personal, non-commercial software development project by Star Development. The goal is to create a simple, fast and transparent antivirus tool that anyone can understand and use.

Features

  • Fast file scanning
  • Real-time protection concept
  • Lightweight and easy to use
  • Open development and regular updates

About Star Development

Star Development is a personal developer project focused on software, security tools and open-source experiments. OpenByte AV is not a business and is not for commercial use.
